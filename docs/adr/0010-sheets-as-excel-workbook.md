# ADR-0010: シート＝Excel の「1ブック＝複数シート」に倣う

> 移植元 single-file-issue（非公開リポ） の **ADR-0005** を v2.0.0 の統合で本家へ移した（本文は当時の記録のまま）。
> 移植元では課題データを `issue.json`、ビューアを `issue_viewer.html` と呼んでいた。v2.0.0 以降はどちらも **`wbs.json` ／ `wbs_viewer.html`** に統一されている。

課題表のファイル1枚を「ブック」とし、案件ごとの「シート」をタブで切り替える。

## ステータス
承認済み（2026-09-07）／**呼び名とキーは [ADR-0011](0011-plan-and-issues-in-one-json.md) で置き換え**（2026-09-07・v0.2）。
「1ファイルに複数の仕切りを並べてタブで切り替える」という**判断そのものは生きている**が、仕切りは「シート（`sheets`）」ではなく「**案件（`projects`）**」と呼び、計画（`tasks`）も同じ仕切りの中に入るようになった。

## コンテキスト
複数の案件を同時に見る人が、案件ごとに `issue.json` を持つと**そのたびにファイルを開き直す**ことになる。
`file://` で開くツールでは、開き直しは「ファイルを開く」→ 編集するなら「保存ダイアログで選び直す」まで含む
（書き込み許可が**セッション限り**のため。[ADR-0002](0002-file-system-access-editing.md)）。
この手間は「更新が続かない」の直接の原因になる。

案は2つあった。

- **A案：1ファイルに複数シート**（Excel と同じ）。タブで切り替える。
- **B案：案件ごとに別 JSON を持ち、複数を同時に開く**。

## 決定
**A案**を採る。データのトップに任意の `sheets: [{ name, issues }]` を置き、画面上部に**タブバー**（先頭に「サマリ」＋シートごとのタブ）を出す。

- 従来形式 `{ name, star, issues }` は**シート1枚のブック**として読む（後方互換・タブバーは出さない）。両方あれば `sheets` を優先。
- **`star`（報告期間）はブック共通**。シートごとには持たない。
- `id` は**シート内で**一意（シートが違えば同じ番号でよい）。
- **サマリ**タブはシートごとの集計表（状態と印の件数＋次の期限＋合計行。列は 2026-09-09 に 未着手／対応中／完了＋印6つへ変更）。行をクリックするとそのシートへ移る。
- **描画は開いているシートだけ**。

## 理由
- **切り替えが1クリックで済む**：案件をまたぐ人が、ファイルを開き直さずに行き来できる。編集の許可も1回で済む。
- **Excel の慣習に合う**：現場は既に「1ブック＝複数シート」で回している。読み方を新しく覚えなくていい。
- **重くならない**：開いているシートだけ描くので、シートが増えても初期描画のコストは1シート分。
- **B案の欠点が決定的**：`file://` の書き込み許可がセッション限りで残らないため、切り替えのたびに開き直しと選び直しが要る。解こうとしている手間が減らない。

## 境界（何をシートで分け、何をファイルで分けるか）
- **シート＝案件の仕切り**。種別（障害／備忘／改善）で分けない。課題・TODO・問題は**1つの表に混ぜる**のが本来
  （[課題管理とはなにか？](https://knowledge.piguo.org/notes/what-is-issue-management/)・[ADR-0009](0009-two-questions-and-close-condition.md)）。
- **ファイル＝報告の単位**。★の期間（`star`）を別々にしたい相手が居るなら、シートではなく**ファイルを分ける**。
  見せたい相手が違うということなので、**セキュリティ上もファイル分割が正しい**（1枚のファイルは丸ごと共有される）。

## 結果
- `star` はブック共通になった（シートごとの報告期間は持たない＝持ちたくなったらファイルを分ける合図）。
- 状態／優先度／期限超過のフィルタと並び順は**ブック共通**、担当の候補と折りたたみの開閉は**シートごと**になった。
- 編集モードに `＋シート`／タブの `✕`／タブのダブルクリックで名前変更 が加わり、**従来形式のファイルは `＋シート` を押した時点で `sheets` 形式へ変換**する。
- シートの追加で表示コードが増えるため、サイズ警報線を **80KB → 100KB** に引き上げた。

- **2026-09-07 追記**：v0.2 で `sheets` は `projects` に置き換わった（[ADR-0011](0011-plan-and-issues-in-one-json.md)）。本 ADR の理由（切り替えが1クリック・Excel の慣習・開いている分だけ描く・B案の欠点）はそのまま `projects` に引き継がれている。
