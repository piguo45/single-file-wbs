# ADR-0011: 計画と課題を1つの JSON に置く（案件＝project・リンク台帳は課題側だけ）

> 移植元 single-file-issue（非公開リポ） の **ADR-0006** を v2.0.0 の統合で本家へ移した（本文は当時の記録のまま）。
> 移植元では課題データを `issue.json`、ビューアを `issue_viewer.html` と呼んでいた。v2.0.0 以降はどちらも **`wbs.json` ／ `wbs_viewer.html`** に統一されている。

`projects[]` の中に 計画（`tasks`）と課題（`issues`）を並べ、つながりは課題の `links[]` にだけ書く。

## ステータス
承認済み（2026-09-07・v0.2）

## コンテキスト
計画（WBS）と課題は、これまで**別のファイル・別のビューア**だった。実際に使うと次が起きる。

- 人：案件を見るのに紙芝居を2枚開く。行き来のたびにファイルを選び直す（`file://` では書き込み許可がセッション限りで、**開き直しがそのまま手数**になる）。
- AI：突き合わせが2ファイルにまたがる。「遅れているタスクに紐づく未決の課題を挙げて」に1文で答えられない。

案は3つあった。

- **A. JSON だけ1つにする**（ビューアは2枚のまま）
- **B. JSON も画面も1つにする**（「計画｜課題」を同じページで切り替える）
- **C. 課題ビューアが `wbs.json` も読んで、吹き出しで計画を見せる**

## 決定
**B**を採る。データは次の形にする。

```
{ name, holidays?, star?, projects: [ { name, milestones?, tasks?, issues? } ] }
```

- **案件（project）＝ `projects[]` の1要素**。`tasks` だけ・`issues` だけ・両方、どれも有効。
- **「シート」という言葉と `sheets` キーは廃止**（v0.1 の呼び方。中身は同じものを指していた）。
- 課題の `id` は**案件の中で一意の整数**。WBS の `id` は wbs のまま**文字列**（`"2.3"`）。**鍵の名前**（`issue` / `wbs`）で種類を区別する。
- **つながりは課題側の `links[]` にだけ書く**。4形のみ：`{ wbs }`／`{ issue }`／`{ project, issue }`・`{ project, wbs }`／`{ title, url }`。
- **`actions[].wbs` は廃止**。WBS の葉 ＝ 課題1件、課題の行動 ＝ その課題の中の手順。

## 理由
- **人の手数が減る**：同じページの中で切り替えるので、ファイルを開き直さない。リンクは1クリック。
- **AI が1ファイルで検算できる**：参照の存在確認も、計画と課題の突き合わせも、1つの JSON を読めば済む。
- **つながりを片側に寄せると壊れない**：両側に書くと必ずズレる。`links` だけを正とし、計画側の「課題 #3」の札は**描画のたびに逆引きして作る**（データに持たない＝[ADR-0008](0008-facts-only-derived-status.md) の「事実だけを持つ」と同じ考え）。
- **A を却下**：ビューアが2枚のままだと、開き直しの手数が減らない（そこが一番の痛み）。
- **C を却下**：片方向で読むだけ。統合すれば要らなくなる。

## 決めなかったこと（意図的）
- **課題番号を WBS の項番（1.1.1）に揃えない**：挿入で番号がずれる／WBS に載せない課題が番号を持てない／保守が増える。番号は案件内の通し番号のままにして、WBS 項番は `links` から導いて隣に出す。
- **案件の不変キーは今は入れない**：案件名が唯一の手がかり。名前を変えたら、指しているリンクも直す（`scripts/check.py` が検出する）。

## 結果
- v0.1 の `sheets` は**読むが書かない**（保存で `projects` に変換）。`actions[].wbs` と課題レベル `assignee` も**読まない・消さない**。
- 案件名が**ブックの中で一意**である必要が生まれた（別案件からのリンクが名前で指すため）。重複は検査でエラー。
- 壊れたリンクは**薄い取り消し線＋ツールチップ**で見せ、データは消さない（graceful）。
- 参照の検算が人の目では足りなくなったので、**依存ゼロの検査スクリプト `scripts/check.py`** を同梱した（リンク先の存在・番号・日付・enum・旧キーの残存）。
- 統合ビューアは **wbs リポ（本リポ）で育てる**（計算式・ガント・保存の聖域・回帰網がそちらにあるため）。**2026-09-11・v2.0.0 で統合済み**。
